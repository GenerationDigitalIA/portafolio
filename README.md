# 🌌 Generation DigitalIA — Creative AI Portfolio

Bienvenido al repositorio oficial del portafolio interactivo de **Generation DigitalIA**. Este sitio reúne experimentos y piezas multimedia generadas con inteligencia artificial de última generación.

🔗 **Sitio en vivo:** [Visitar Portafolio](https://generationdigitalia.github.io/portafolio/)

---

## 🛠️ Stack & Almacenamiento

* **Hosting:** GitHub Pages
* **Imágenes:** Optimizadas y servidas a través de Cloudinary CDN
* **Audio:** Embebido vía SoundCloud
* **Video:** Canal oficial de YouTube
* **Frontend:** HTML5 semántico, CSS3 modular y JavaScript moderno
